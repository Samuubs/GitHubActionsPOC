# Instruções para Agentes de Código

## Permissões e Escopo
- Você está autorizado a criar, editar e remover arquivos dentro deste repositório quando solicitado.
- Mantenha as alterações focadas na tarefa pedida, sem reescrever partes não relacionadas do código.
- Peça confirmação antes de alterar arquivos de configuração sensíveis (como `.env`, credenciais ou pipelines de produção).

## Padrões do Projeto
- Escreva código claro, modular e fácil de manter.
- Siga o estilo e as convenções já existentes nos arquivos do repositório.
- Explique resumidamente quais arquivos foram alterados e por quê após concluir uma tarefa.
